## 📚 Contenido Técnico

### 1. Gestión de Excepciones (Exception Handling)
En las clases correspondientes, implementé un sistema para capturar fallos comunes durante la ejecución:
- **Bloque Try-Catch**: Se utiliza para intentar realizar operaciones sensibles (como divisiones) y capturar errores de tipo `ArithmeticException` o entradas de datos inválidas.
- **Bloque Finally**: Se incluye para asegurar la limpieza de recursos y confirmar la finalización del proceso.

### 2. Programación Orientada a Objetos
Dentro del proyecto se aplican los siguientes pilares:
- **Herencia y Sobrescritura**: Creación de jerarquías de clases para reutilizar código y modificar comportamientos heredados.
- **Abstracción**: Uso de clases abstractas e interfaces.
- **Encapsulamiento**: Uso de `private` con getters/setters.
- **Polimorfismo**: Dynamic binding con métodos sobrescritos.

### 3. Conceptos adicionales cubiertos
- Variables, Scope y Type Casting
- Lambda Expressions
- Optionals (Java 8+)
- Enums, Records, Method Chaining
- Initialize Blocks (static e instance)
- Pass by Value vs Pass by Reference
