ProgramacionPOO
​Este proyecto consiste en la implementación práctica de conceptos avanzados de Programación Orientada a Objetos y la gestión de errores mediante excepciones, estructurado de forma modular en paquetes.
​💻 Explicación del Código
​El proyecto se divide en las siguientes funcionalidades clave:
​1. Gestión de Excepciones (Exception Handling)
​En la clase ManejoErrores.java, implementé un sistema para capturar fallos comunes durante la ejecución:
​Bloque Try-Catch: Se utiliza para intentar realizar operaciones sensibles (como divisiones) y capturar errores de tipo ArithmeticException o entradas de datos inválidas.
​Bloque Finally: Se incluyó para asegurar la limpieza de recursos y confirmar la finalización del proceso, garantizando que el programa no se detenga bruscamente.
​2. Estructura de Programación Orientada a Objetos
​Dentro del paquete de conceptos, se aplicaron los siguientes pilares:
​Herencia y Sobrescritura: Creación de jerarquías de clases para reutilizar código y modificar comportamientos heredados.
​Abstracción: Definición de métodos sin implementación para obligar a las clases hijas a definir sus propias acciones.
​Encapsulamiento: Protección de datos mediante atributos privados y acceso controlado con métodos Getter y Setter.
​Enumeraciones (Enums): Uso de tipos de datos fijos para representar valores constantes (como días de la semana).
​📁 Estructura del Repositorio
​/src/introduccion/conceptos/excepciones: Contiene la lógica de control de errores.
​/src/introduccion/conceptos/more_poo: Contiene las clases de lógica avanzada y la clase Principal.
​🛠️ Instrucciones de Ejecución
​El proyecto incluye métodos main estratégicos para facilitar la revisión:
​Se puede ejecutar de forma independiente la clase ManejoErrores para probar la captura de fallos.
​La clase Principal integra y ejecuta todos los conceptos de POO de manera secuencial.
